# AI Code Reviewer- https://ai-code-reviewer-io.onrender.com

## Overview

AI Code Reviewer is a web application that allows users to submit code and receive reviews generated by an AI model. The application consists of a frontend built with React and a backend built with Express.

## Features

- Submit code for review
- Receive AI-generated code reviews
- Syntax highlighting for code snippets

## Technologies Used

### Frontend

- React
- Prism.js for syntax highlighting
- Axios for HTTP requests

### Backend

- Node.js
- Express
- CORS
- dotenv for environment variable management

## Installation

### Prerequisites

- Node.js
- npm (Node Package Manager)

### Steps

1. Clone the repository:

   ```sh
   git clone https://github.com/your-username/code-reviewer.git
   ```

2. Navigate to the project directory:

   ```sh
   cd code-reviewer
   ```

3. Install dependencies for both frontend and backend:

   ```sh
   cd Backend
   npm install
   cd ../Frontend
   npm install
   ```

4. Create a `.env` file in the [Backend](http://_vscodecontentref_/2) directory and add your environment variables:

   ```env
   PORT=3000
   GOOGLE_GEMINI_KEY=your-google-gemini-key
   ```

5. Start the backend server:

   ```sh
   cd Backend
   npm start
   ```

6. Start the frontend development server:

   ```sh
   cd ../Frontend
   npm start
   ```

7. Open your browser and navigate to `http://localhost:5173` to use the application.

## Usage

1. Enter your code in the editor on the left side of the screen.
2. Click the "Review" button to submit your code for review.
3. The AI-generated review will be displayed on the right side of the screen.
